Aide et contact

Application Gazouille

Une question, un problème ? Écrivez-nous à contact@gazouille.cloud.

Pour un problème technique, indiquez le modèle de votre iPhone et sa version d'iOS.

Mot de passe oublié

Sur l'écran de connexion, touchez Mot de passe oublié ? et suivez le lien reçu par email.

Changer d'iPhone

Connectez-vous avec le même compte sur le nouvel appareil. Vos données de santé sont chiffrées, et la clé qui permet de les lire passe d'un appareil à l'autre par le trousseau iCloud : vérifiez qu'il est activé dans Réglages → votre nom → iCloud → Mots de passe et trousseau.

Si le trousseau iCloud était désactivé et que l'ancien iPhone n'est plus disponible, les données de santé ne peuvent plus être déchiffrées, par personne, nous compris.

Les rappels n'arrivent pas

Vérifiez que les notifications de Gazouille sont autorisées dans Réglages → Notifications → Gazouille, puis choisissez les rappels voulus depuis l'icône de profil de l'application.

Utiliser l'application hors ligne

Tout fonctionne sans réseau. Vos saisies sont envoyées dès que la connexion revient.

Retirer votre consentement santé

Depuis l'application : icône de profil → Compte → Retirer mon consentement santé. Les données de santé sont alors effacées définitivement. Le détail figure dans la politique de confidentialité.

Supprimer votre compte

Depuis l'application : icône de profil → Compte → Supprimer mon compte. La suppression est immédiate et définitive, sans démarche auprès de nous.
